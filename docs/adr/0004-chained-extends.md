# 模板条目支持链式 extends,每一跳按查找链就近解析

为消除"变体之间仍要复制参数"的残余重复,我们允许模板条目顶层书写 `extends` 指向另一模板条目(模板文件是自定义格式,无需像 opencode.json 那样把 extends 藏进 settings;见 ADR-0001 的约束不适用于此)。链的解析规则:每一跳都沿完整查找链(项目就近 → 远 → 全局)重新定位 id,就近者赢;合并顺序为 用户配置 > 就近模板 > 更远模板 > 全局模板 > 链上游。检测到环或断链时警告并停止展开,已合并部分仍生效。

## Consequences

- 被否掉的 (A)(禁止链式)省下的复杂度会以用户复制粘贴的形式还回来。
- 插件需要一个 visited-set 环检测;id 跨文件同名时,链式使"就近赢"的语义必须逐跳成立,实现时不能一次性拍平查找链。
