# 合并采用逐字段深合并,显式 null 删除模板键

用户配置与模板条目的合并,我们决定按字段逐层深合并(对象递归、数组/标量整值替换、variants 按 id 对齐),而不是同名字段整体替换;并要求用户端显式 `null` 表示"删除模板带来的该键",注入时连 key 一起移除、不透传给 SDK。

## Consequences

- 深合并与 OpenCode 文档的 options 合并语义一致,用户只写差异项;整体替换会逼用户复制模板内容,消灭复用价值。
- `null` 删除是一条自定义语义(OpenCode 原生配置没有),必须在插件文档中显著说明;否则用户无法表达"我不要模板里这个默认值",只能被模板绑架。
