# 模板文件支持 {env:VAR} 替换,变量未设时删除该键

`extends.models.jsonc` 由插件自行读取,OpenCode 的配置变量替换不会作用于它。为让模板能安全进 git 且承载多上游 key 场景,插件实现 `{env:VAR}` 一种占位语法(不支持 `{file:}`,无对应需求)。变量未设时:警告并删除该键,而不是把字面量 `"{env:X}"` 注入 SDK 换回一个困惑的 401。

## Consequences

- "未设即删"是插件自定义语义,与 OpenCode 自身对未设 env 的处理可能不同,必须在 README 显著说明。
- 凭据仍应只以占位符出现在模板中,真值一律留在环境变量。
